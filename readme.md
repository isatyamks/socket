# ChatIn Lab 🧪

## Overview
Ever found yourself staring blankly at your lab screen while your friend in the hostel has all the answers? ChatIn Lab is your secret weapon for those "I have no idea what's happening in this practical" moments! 🚀

This sneaky little terminal-based app lets you and your hostel buddies collaborate in real-time during those nerve-wracking lab sessions. The best part? It looks just like a regular terminal window to any passing lab instructor! Whether you're trying to figure out why your code won't compile or need the answers to those tricky lab questions, ChatIn Lab has got your back! 

## Features
- Real-time SOS messages to your hostel friends 📱
- Password protection (because we're not trying to get caught! 🔒)
- Support for multiple users (the more, the merrier! 👥)
- Lightweight and efficient (runs faster than your lab instructor can spot you)
- Terminal-based interface (looks like you're just coding, not chatting! 💻)
- Discreet operation (we're ninjas, not hackers 🥷)
- Stealth mode (Alt+Tab to your IDE if the teacher walks by)

## Quick Start
1. Download the `ChatInLab.exe` file (your new best friend in practicals)
2. Run the `ChatInLab.exe` file (it looks like a normal terminal window)
3. Enter the password (it's like the secret handshake)
4. Enter your username (pick something cool, but not too obvious)
5. Start communicating! (Your practical just got a whole lot easier)

Pro Tip: Keep your IDE open in another window. If a teacher approaches, just Alt+Tab to your code - they'll think you're debugging! 😉

## For Developers (AKA The Tech-Savvy Friends)
If you're the one who's actually building this for your friends:

### Prerequisites
- Python 3.x (because we're not savages)
- Basic understanding of socket programming (or just copy-paste skills)
- Network setup (make sure the lab WiFi isn't blocking us)

### Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/chatinlab.git
    ```
2. Navigate to the project directory:
    ```bash
    cd chatinlab
    ```
3. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

### Running from Source
1. Start the server (your friend in the hostel):
    ```bash
    python app.py
    ```
2. Start the client (you in the lab):
    ```bash
    python client.py
    ```
3. Enter the password (don't forget it!)
4. Enter your username (be creative)
5. Start communicating! (Your practical just got a whole lot easier)

## File Structure
- `app.py`: The server that runs in your hostel (where the smart friends are)
- `client.py`: The client that runs in the lab (where you're panicking)
- `ChatInLab.exe`: The executable that saves your grades
